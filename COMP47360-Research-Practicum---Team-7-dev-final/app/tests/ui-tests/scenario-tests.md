# Scenario Testing Report

As suggested by team members, we decided to include scenario-based usability testing conducted with reference to initial user needs and stories. Each scenario simulates a real user's interaction with CrowdScope, verifying usability improvements since our initial research.

---

## SCN-01: First-Time User Guidance/ Tutorial button Loading

**Description**: Can a first-time user intuitively understand what CrowdScope is?

- **Steps Taken**:
  - Opened homepage
  - Observed text, logo, and visuals
- **Expected Outcome**: User understands product purpose within 10 seconds, can use Tutorial page in case they cannot navigate
- **Result**: User identified that the platform shows crowd levels across attractions in Manhattan
- **Status**: Pass

---

## SCN-02: Navigation to Map View

**Description**: Can the user find and open the map view?

- **Steps Taken**:
  - Clicked "Explore" or interacted with landing page CTA
- **Expected Outcome**: User finds the map view within one click of the button
- **Result**: User successfully navigated to `crowdScope.html`
- **Status**: Pass

---

## SCN-03: Interacting with Hotspots and HeatMap

**Description**: Can users interact with location markers and understand information displayed?

- **Steps Taken**:
  - Clicked on restaurant, park, gallery icons
- **Expected Outcome**: Popup with data appears, user understands the context
- **Result**: User correctly interpreted crowd level icons and labels
- **Status**: Pass

---

## SCN-04: Filtering by Category/ Favorites button

**Description**: Can users use category filters to view specific POI types?

- **Steps Taken**:
  - Clicked filter icons on top bar
- **Expected Outcome**: Map updates to reflect filter
- **Result**: Correct POIs displayed for each filter
- **Status**: Pass

---

## SCN-05: Interpreting Crowd Predictions and understanding the Time slider

**Description**: Can users interpret prediction scales visually?

- **Steps Taken**:
  - Observed map zones with gradient coloring
  - Asked to describe 3 sample zones
- **Expected Outcome**: User correctly distinguishes between crowded and less crowded zones
- **Result**: All three zones interpreted correctly, as RGB Color scheme suffices. 
- **Status**: Pass
