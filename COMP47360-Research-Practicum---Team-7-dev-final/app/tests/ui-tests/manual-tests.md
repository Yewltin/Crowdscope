# Manual Testing Report

This report captures hands-on testing by a human user simulating real usage scenarios. All major frontend features were tested for functionality, layout, and responsiveness by the maintainence lead as well as the team members collectively, from time to time to ensure all worked perfectly!

---

## MNL-01: Button Functionality

**Description**: Are interactive buttons working?

- **Actions**: Clicked recenter, zoom-in/out, filter buttons, home nav, attraction categories
- **Expected**: Each action performs correctly
- **Result**: All buttons executed expected functions
- **Status**: Pass

---

## MNL-02: Hover and Feedback Effects

**Description**: Do interactive elements respond visually?

- **Actions**: Hovered over markers and icons
- **Expected**: Cursor change or tooltip/animation shown
- **Result**: Cursor changed, popups and tooltips worked
- **Status**: Pass

---

## MNL-03: Responsive Layout

**Description**: Is the site mobile/tablet friendly?

- **Actions**: Tested on Chrome DevTools iPhone SE, iPad
- **Expected**: Layout adjusts, buttons remain clickable, no overlap
- **Result**: All pages responsive and usable
- **Status**: Pass

---

## MNL-04: Broken Links and Missing Media

**Description**: Are all links and media assets working?

- **Actions**: Navigated across pages and clicked every button
- **Expected**: No 404s, all images/icons loaded
- **Result**: No missing files or broken routes
- **Status**: Pass

---

## MNL-05: Load Time and Map Performance

**Description**: Does the page load fast with smooth performance?

- **Actions**: Timed homepage and map view load; interacted with zones
- **Expected**: Loads in under 3s, map renders without lag
- **Result**: Homepage in 1.2s, map view in 2.4s, no delays
- **Status**: Pass
