# Manhattan POI Dataset and Crowd Flow Prediction (2025–2026)

This repository provides two independent but complementary components:

1. **POI Dataset for Manhattan**
2. **Pedestrian Flow Prediction from July 2025 to June 2026**

These two parts serve different purposes. The POI dataset offers a curated and geocoded set of places of interest for Manhattan, while the prediction component includes data processing, model training, and output generation for future pedestrian flows.

---

## 📍 1. POI Dataset (`/POI`)

This module refines and expands the raw POI data from OpenStreetMap and other sources. It includes:

- Original POI extraction and filtering by category (`shop`, `amenity`, `tourism`, etc.)
- Geolocation correction using external APIs
- De-duplication and type-based grouping (e.g., museums, galleries, parks, restaurants, shops)
- Final output: A merged and validated POI dataset in GeoJSON format

> 📂 Folder: `POI/`  
> 📄 Output file: `merged_POI.geojson`

This POI dataset is a standalone product and was **not used in the prediction model**, but its category tags were applied to the interactive filtering feature on the map page. It is also suitable for spatial planning and visualization purpose.

---

## 🚶‍♂️ 2. Pedestrian Flow Prediction (`/Raw_data`, `/Predicted_Flow_Jul25_Jun26`, etc.)

This section generates hourly crowd flow predictions across Manhattan for the period **July 1, 2025 to June 30, 2026** using machine learning techniques.

### Data Sources

- `Raw_data/`:  
  - MTA Subway Hourly Ridership  
  - MTA Bus Hourly Ridership  
  - Yellow Taxi Trip Records (with zone definitions from NYC TLC)

- `MapPLUTO25v2.gdb/`:  
  Official land use and parcel data from NYC Planning (DCP)

### Model Workflow

- `data_processing&model_training.ipynb`:  
  Full pipeline for data cleaning, feature engineering, and training a Random Forest model

- `joblib_file_google_drive.txt`:  
  Link to download the pre-trained `.joblib` model file

- `Predicted_Flow_Jul25_Jun26/`:  
  Final prediction results in GeoJSON format (hourly resolution, one year coverage)

> ⚠️ Intermediate `.csv` files generated during training are excluded for size reasons. To reproduce results, please run the notebook locally.
